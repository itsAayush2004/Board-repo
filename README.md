# Aayush — Portfolio Board

A corkboard portfolio with pinned sticky notes: websites, game apps, AI automation systems, reels and the AKVerse YouTube UI system.

Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → deploy from this branch) to host it.

Placeholders in `[BRACKETS]` (photo, second website, email, YouTube handle, current work) are yours to fill in.
